# คู่มือผู้ดูแลระบบ (Admin) — ระบบ HR-Interview

สำหรับ: ผู้ดูแลระบบของบริษัท

คู่มือเล่มนี้ครอบคลุมงานผู้ดูแลระบบทั้งหมดของบริษัท ตั้งแต่จัดโครงสร้างองค์กร จัดการผู้ใช้ ตั้งวันหยุด เปิด/ปิด AI สำรองข้อมูลของบริษัท ไปจนถึงการลบข้อมูลในโซนอันตราย — อ่านเล่มเดียวดูแลระบบของบริษัทได้ครบ

---

## 1. เริ่มต้น — เข้าและออกจากระบบ

### 1.1 เข้าสู่ระบบในฐานะผู้ดูแล

1. เปิดเบราว์เซอร์ (Chrome, Edge, Safari หรือ Firefox)
2. พิมพ์ที่อยู่เว็บของบริษัท (ลงท้ายประมาณว่า `.../login`) แล้วกด Enter
3. ในช่อง **ชื่อผู้ใช้ (Username)** พิมพ์คำว่า `admin`
4. ในช่อง **รหัสผ่าน** พิมพ์รหัส Master Admin ของบริษัท
5. กดปุ่ม "เข้าสู่ระบบ"

> รหัส Master Admin ครั้งแรกได้รับจากผู้ดูแลระดับสูง (Super Admin) ที่สร้างบริษัทให้ ควรเปลี่ยนเป็นรหัสของคุณเองทันที (ดูหัวข้อ 5)

### 1.2 ออกจากระบบ

กดปุ่ม "ออกจากระบบ" ที่มุมขวาบนทุกครั้งเมื่อใช้งานเสร็จ โดยเฉพาะบนเครื่องที่ใช้ร่วมกัน

### 1.3 ศูนย์กลางของผู้ดูแล

เมนู "Admin" คือหน้า Admin Console — เป็นศูนย์รวมทางลัดและการ์ดตั้งค่าทั้งหมด ได้แก่ โครงสร้างองค์กร จัดการผู้ใช้ Dashboard รายงาน รหัส Master Admin การตั้งค่า Claude AI วิเคราะห์เอกสารใหม่ทั้งระบบ วันหยุดบริษัท แจ้งเตือนมือถือ สำรองข้อมูล โซนอันตราย และข้อมูลโดยสรุป

---

## 2. โครงสร้างองค์กร

ระบบจัดข้อมูลเป็นลำดับชั้น 4 ระดับ ต้องสร้างจากบนลงล่าง: ฝ่าย > แผนก > ตำแหน่ง > พนักงาน

### ถ้าเริ่มตั้งระบบใหม่ (แนะนำลำดับนี้)

1. กดการ์ด "โครงสร้างองค์กร" ในหน้า Admin
2. สร้าง **ฝ่าย** ทั้งหมดก่อน (ตั้งชื่อ เลือกไอคอนและสี)
3. สร้าง **แผนก** ในแต่ละฝ่าย
4. สร้าง **ตำแหน่ง** ในแต่ละแผนก
5. จากนั้นจึงไปสร้างผู้ใช้แล้วผูกกับตำแหน่ง (หัวข้อ 3)

**ตัวอย่าง:** สร้างฝ่าย "ฝ่ายขาย" > ในฝ่ายนี้สร้างแผนก "แผนกขายหน้าร้าน" > ในแผนกนี้สร้างตำแหน่ง "พนักงานขาย" > แล้วค่อยสร้างผู้ใช้ชื่อสมชายผูกกับตำแหน่งพนักงานขาย

---

## 3. จัดการผู้ใช้

กดการ์ด "จัดการผู้ใช้" ในหน้า Admin เพื่อเพิ่ม แก้ไข หรือลบผู้ใช้

### ถ้าอยากเพิ่มผู้ใช้ทีละคน

1. กดปุ่มเพิ่มผู้ใช้ใหม่
2. กรอก ชื่อ-นามสกุล, ชื่อผู้ใช้ (username), รหัสผ่านเริ่มต้น
3. เลือก **บทบาท (role)** เช่น เจ้าหน้าที่ หัวหน้าแผนก ผู้จัดการ ฯลฯ
4. เลือก **ฝ่าย / แผนก / ตำแหน่ง** ที่สังกัด (ต้องครบทั้ง 3 ระดับ)
5. กำหนดเวลาทำงาน (เข้างาน-เลิกงาน และเวลาพัก) — ใช้เป็นช่วงชั่วโมงในหน้าบันทึกงานของคนนั้น
6. บันทึก

ข้อกำหนดที่ต้องรู้:

- ห้ามใช้ชื่อผู้ใช้ว่า `admin` (สงวนไว้สำหรับบัญชีผู้ดูแล)
- ผู้ใช้ทุกคน (ยกเว้น admin) ต้องมีครบทั้งฝ่าย/แผนก/ตำแหน่ง
- เมื่อสร้างผู้ใช้พร้อมตำแหน่ง ระบบจะสร้างระเบียนพนักงานสำหรับตำแหน่งนั้นให้อัตโนมัติ

### ถ้าอยากนำเข้าผู้ใช้จำนวนมากด้วย Excel

1. ในหน้าจัดการผู้ใช้ ดาวน์โหลด **เทมเพลต** (มีทั้งเทมเพลตโครงสร้างองค์กรและเทมเพลตผู้ใช้)
2. กรอกข้อมูลตามคอลัมน์ในไฟล์ (มีชีต "ค่าที่ใช้ได้" แสดงรายการฝ่าย/แผนก/ตำแหน่งปัจจุบันให้อ้างอิง)
3. อัปโหลดไฟล์กลับเข้าระบบ
4. ระบบจะรายงานผล และแจ้งแถวที่มีปัญหาถ้ามี

> แนะนำให้สร้างโครงสร้างองค์กรก่อน แล้วค่อยนำเข้าผู้ใช้ เพราะผู้ใช้ต้องอ้างอิงฝ่าย/แผนก/ตำแหน่งที่มีอยู่แล้ว

---

## 4. Dashboard และรายงาน

- **Dashboard:** ดูสถานะการสัมภาษณ์ของทุกตำแหน่ง สลับมุมมอง "ตามตำแหน่ง / รายคน" ดูใครกรอก/ยังไม่กรอก และกด "ดูเอกสาร" ของแต่ละคน ในฐานะ admin คุณยังกดปุ่ม "รีเซ็ต" หลังชื่อคนได้ เพื่อล้างคำตอบและเอกสารของคนนั้นกลับเป็น "ยังไม่ตอบ" (ตัวพนักงานยังอยู่ กรอกใหม่ได้)
- **รายงาน:** ดูสรุปจำนวนผู้ใช้ จำนวนแยกตามฝ่าย และรายชื่อผู้ใช้ทั้งหมดพร้อมเวลาทำงาน

---

## 5. เปลี่ยนรหัส Master Admin

1. ในหน้า Admin กดการ์ด "รหัส Master Admin"
2. พิมพ์รหัสผ่านใหม่ (อย่างน้อย 6 ตัวอักษร)
3. กดตกลง — ครั้งหน้าให้ใช้รหัสใหม่นี้เข้าระบบ

> รหัสปัจจุบันถูกเข้ารหัสไว้ ดูค่าเดิมไม่ได้ ถ้าลืมรหัส จะต้องแก้ไฟล์ข้อมูลบนเซิร์ฟเวอร์โดยตรง (แจ้งผู้ดูแลเซิร์ฟเวอร์) ดังนั้นเก็บรหัสใหม่ไว้ในที่ปลอดภัย

---

## 6. ตั้งค่าวันหยุดของบริษัท

การตั้งวันหยุดทำให้ระบบไม่เตือนพนักงานในวันหยุด และไม่นับวันหยุดเป็น "วันขาด" ในรายงานบันทึกงาน

### ถ้าอยากตั้งวันหยุด

1. ในหน้า Admin เลื่อนไปที่การ์ด "วันหยุดของบริษัท"
2. **วันหยุดประจำสัปดาห์:** กดเลือกวันที่บริษัทหยุดทุกสัปดาห์ (เช่น เสาร์-อาทิตย์) วันที่เลือกจะเป็นสีเขียว
3. **วันหยุดเฉพาะวัน:** เลือกวันที่ในช่องวันที่ แล้วกด "+ เพิ่มวันหยุด" (เพิ่มได้หลายวัน)
4. หากต้องการวันหยุดราชการไทยทั้งปี กดปุ่ม "เติมวันหยุดราชการไทย (ปีนี้)" ระบบจะเติมให้อัตโนมัติ
5. กดปุ่ม "บันทึกวันหยุด" เมื่อเสร็จ

> วันหยุดที่อิงจันทรคติ (เช่น มาฆบูชา วิสาขบูชา อาสาฬหบูชา เข้าพรรษา) เปลี่ยนทุกปี — ปุ่มเติมอัตโนมัติจะไม่รวมให้ ต้องเพิ่มเองด้วยช่อง "เพิ่มวันหยุด"

---

## 7. Claude AI — เปิด/ปิด และดูค่าใช้จ่าย

Claude AI คือส่วนที่ให้ระบบใช้ปัญญาประดิษฐ์สร้างเอกสาร (ใบกำหนดหน้าที่งาน KPI ข้อเสนอปรับปรุงงาน ฯลฯ) ตอนกด "เสร็จสิ้นสัมภาษณ์" และ "วิเคราะห์ภาพรวมองค์กร"

### ถ้าอยากเปิดหรือปิด Claude AI

1. ในหน้า Admin เลื่อนไปที่การ์ด "Claude AI"
2. กดสวิตช์ เปิด = ใช้ AI วิเคราะห์จริง · ปิด = ใช้เทมเพลตสำเร็จรูป (ฟรี ไม่มีค่าใช้จ่าย)
3. ระบบจะให้กรอก **รหัส Admin** เพื่อยืนยันทุกครั้ง กรอกแล้วกดตกลง

### ดูค่าใช้จ่ายและการใช้งาน

การ์ดเดียวกันนี้แสดง:

- **สถานะ API Key บนเซิร์ฟเวอร์:** บอกว่าตั้งค่ากุญแจ AI บนเซิร์ฟเวอร์แล้วหรือยัง ถ้ายังไม่ตั้ง แม้เปิดสวิตช์ ระบบก็จะยังใช้เทมเพลตจนกว่าจะตั้งกุญแจ (แจ้งผู้ดูแลเซิร์ฟเวอร์)
- **การใช้งานสะสม:** จำนวนครั้งที่วิเคราะห์ จำนวนโทเคน (token) เข้า-ออก และค่าใช้จ่ายโดยประมาณ (บาท/ดอลลาร์) เฉพาะของบริษัทนี้
- **ประวัติการวิเคราะห์ล่าสุด:** ตารางรายครั้งว่าใช้โทเคนและค่าใช้จ่ายเท่าใด
- **ปุ่มล้างตัวนับการใช้งาน:** ล้างยอดสะสมและประวัติ

> ค่าใช้จ่ายเป็นการประมาณจากอัตราค่าโทเคนของโมเดล ใช้ดูแนวโน้มการใช้งาน

## 8. วิเคราะห์เอกสารใหม่ทั้งระบบ

ถ้าต้องการสร้างเอกสารชุดใหม่ให้พนักงานที่สัมภาษณ์เสร็จ **ทุกคน** ในครั้งเดียว (เช่น หลังปรับหมวดหมู่งาน หรืออยากให้เอกสารใช้บันทึกงานล่าสุด) ใช้การ์ดนี้

1. ในหน้า Admin เลื่อนไปที่การ์ด "วิเคราะห์เอกสารใหม่ — ทั้งระบบ"
2. เลือก "ใช้บันทึกงานย้อนหลัง" กี่เดือน (1/2/3 เดือน หรือไม่ใช้)
3. กดปุ่ม "วิเคราะห์ใหม่ทั้งหมด"
4. ระบบจะถามยืนยัน แล้วให้กรอกรหัส Admin
5. จะมีแถบความคืบหน้าแสดงว่าทำไปกี่คนแล้ว รอจนขึ้นว่าเสร็จ

> ข้อควรระวัง: ถ้าเปิด Claude AI อยู่ การวิเคราะห์ใหม่จะมีค่าใช้จ่ายต่อคน (ดูยอดที่การ์ด Claude AI) และถ้าคนเยอะจะใช้เวลาสักครู่ · คำตอบสัมภาษณ์เดิมไม่หาย ระบบสร้างเอกสารใหม่ทับของเดิมเท่านั้น

## 9. แจ้งเตือนกรอกงานเข้ามือถือ — เปิด/ปิดทั้งบริษัท

การ์ด "แจ้งเตือนกรอกงานเข้ามือถือ" ในหน้า Admin ใช้ควบคุมการแจ้งเตือนภาพรวมของทั้งบริษัท

1. ในหน้า Admin เลื่อนไปที่การ์ด "แจ้งเตือนกรอกงานเข้ามือถือ"
2. กดสวิตช์:
   - เปิด = พนักงานที่ติดตั้งแอปและเปิดแจ้งเตือนบนมือถือตัวเองไว้ จะได้รับการเตือนเมื่อลืมกรอกงาน (ข้ามวันหยุด/วันลาให้อัตโนมัติ)
   - ปิด = ทั้งบริษัทจะไม่มีใครได้รับการแจ้งเตือน แม้พนักงานจะเปิดไว้ที่เครื่องตนแล้วก็ตาม

> สวิตช์นี้คุมภาพรวมทั้งบริษัท ส่วนพนักงานแต่ละคนยังต้องเปิดแจ้งเตือนที่มือถือตัวเองด้วย (ที่หน้าบันทึกงาน) จึงจะได้รับการเตือน · ถ้าเห็นข้อความเตือนว่าเซิร์ฟเวอร์ยังไม่ได้ติดตั้งไลบรารีแจ้งเตือน ให้แจ้งผู้ดูแลเซิร์ฟเวอร์

---

## 10. สำรองข้อมูลบริษัท

การ์ด "สำรองข้อมูลบริษัท" ในหน้า Admin ให้คุณสำรองและดาวน์โหลดข้อมูล **เฉพาะบริษัทของคุณ** ได้เอง โดยไม่ปนกับบริษัทอื่น

### ถ้าอยากสำรองข้อมูลตอนนี้

1. ในหน้า Admin เลื่อนไปที่การ์ด "สำรองข้อมูลบริษัท"
2. กดปุ่ม "สำรองตอนนี้"
3. รอสักครู่ จะขึ้นข้อความว่าสำรองสำเร็จ พร้อมชื่อไฟล์และขนาด
4. ไฟล์ใหม่จะปรากฏในรายการ "ไฟล์สำรองที่มีอยู่" ด้านล่าง

### ถ้าอยากดาวน์โหลดหรือลบไฟล์สำรอง

- กดปุ่ม "ดาวน์โหลด" หลังไฟล์ที่ต้องการ เพื่อบันทึกลงเครื่องคุณ
- กดปุ่ม "ลบ" เพื่อลบไฟล์สำรองที่ไม่ต้องการ (ระบบจะถามยืนยันก่อน ลบแล้วกู้ไฟล์นั้นไม่ได้)

> สำคัญมาก: ไฟล์สำรองที่เก็บบนเซิร์ฟเวอร์อย่างเดียว จะหายไปด้วยถ้าเซิร์ฟเวอร์เสียหาย — ควร **ดาวน์โหลดไฟล์สำรองไปเก็บนอกเซิร์ฟเวอร์** (เช่น เครื่องของคุณ หรือ Google Drive) อย่างสม่ำเสมอ

**ตัวอย่าง:** ก่อนจะแก้โครงสร้างองค์กรครั้งใหญ่ ให้เข้าการ์ด "สำรองข้อมูลบริษัท" กด "สำรองตอนนี้" แล้วกด "ดาวน์โหลด" ไฟล์ล่าสุดเก็บไว้ในเครื่อง ถ้าแก้แล้วมีปัญหา ก็มีไฟล์สำรองไว้กู้คืนได้

## 11. โซนอันตราย (Danger Zone) — ลบข้อมูล

โซนนี้ใช้ลบข้อมูลเป็นกลุ่ม ทุกปุ่มต้องพิมพ์คำว่า `DELETE` (ตัวพิมพ์ใหญ่) ยืนยัน และลบแล้วกู้คืนไม่ได้ ใช้ด้วยความระมัดระวัง

> ก่อนใช้ปุ่มในโซนนี้ทุกครั้ง ให้สำรองข้อมูลก่อน (ดูหัวข้อ 10)

ปุ่มในโซนนี้:

1. **ลบ User ทั้งหมด** — เคลียร์ผู้ใช้รายคน แต่เก็บโครงสร้างองค์กรและประวัติการสัมภาษณ์ไว้
2. **ลบ ฝ่าย/แผนก/ตำแหน่ง** — เคลียร์โครงสร้างองค์กร และลบผู้ใช้/พนักงาน/การสัมภาษณ์ที่อ้างอิงกันด้วย
3. **ลบข้อมูลที่ User กรอก** — เคลียร์เฉพาะคำตอบสัมภาษณ์และเอกสารที่สร้าง (รีเซ็ตสถานะกลับเป็น "ยังไม่ตอบ") เก็บผู้ใช้และองค์กรไว้
4. **ลบข้อมูลทั้งหมด** — รีเซ็ตทั้งระบบของบริษัท เหลือเพียงรหัสผู้ดูแล

### รีเซ็ตการสัมภาษณ์รายคน (ทางเลือกที่ปลอดภัยกว่า)

ถ้าต้องการให้พนักงานคนหนึ่งกรอกสัมภาษณ์ใหม่ ไม่ต้องใช้โซนอันตราย ให้ทำที่ Dashboard แทน:

1. เข้าเมนู "Dashboard"
2. หาชื่อคนที่ต้องการ
3. กดปุ่ม "รีเซ็ต" หลังชื่อ — ระบบจะล้างเฉพาะคำตอบและเอกสารของคนนั้น กลับเป็น "ยังไม่ตอบ" โดยไม่ลบตัวพนักงาน เพื่อให้กรอกใหม่ได้

## 12. ข้อมูลโดยสรุป

การ์ด "ข้อมูลโดยสรุป" ในหน้า Admin แสดงภาพรวมของบริษัทแบบรายบรรทัด: ชื่อบริษัท จำนวนฝ่าย จำนวนแผนก จำนวนตำแหน่ง และจำนวนผู้ใช้ ใช้ตรวจดูความครบถ้วนของข้อมูลได้อย่างรวดเร็ว

## 13. คำถามที่พบบ่อย (FAQ)

**ถาม: บัญชี admin เปลี่ยนรหัสผ่านหรือแก้โปรไฟล์ที่เมนูโปรไฟล์ได้ไหม**
ตอบ: บัญชี admin ไม่มีโปรไฟล์ส่วนตัว การเปลี่ยนรหัสทำที่การ์ด "รหัส Master Admin" ในหน้า Admin

**ถาม: เปิด Claude แล้วทำไมยังขึ้นว่าใช้เทมเพลต (Mock)**
ตอบ: ต้องตั้งค่ากุญแจ AI (API Key) บนเซิร์ฟเวอร์ก่อน เมื่อตั้งแล้วและเปิดสวิตช์ ระบบจึงจะใช้ AI จริง แจ้งผู้ดูแลเซิร์ฟเวอร์ให้ตั้งค่า

**ถาม: พนักงานบอกว่าไม่ได้รับแจ้งเตือนบนมือถือ**
ตอบ: ตรวจ 3 อย่าง (1) สวิตช์แจ้งเตือนทั้งบริษัทในหน้า Admin เปิดอยู่ (2) พนักงานติดตั้งแอปและกดเปิดแจ้งเตือนที่มือถือตัวเองแล้ว (3) เซิร์ฟเวอร์ติดตั้งไลบรารีแจ้งเตือนแล้ว (ถ้ามีข้อความเตือนในการ์ดให้แจ้งผู้ดูแลเซิร์ฟเวอร์)

**ถาม: นำเข้า Excel แล้วบางแถวไม่เข้า**
ตอบ: ระบบจะรายงานแถวที่มีปัญหา มักเป็นเพราะอ้างอิงฝ่าย/แผนก/ตำแหน่งที่ยังไม่มี หรือชื่อผู้ใช้ซ้ำ ให้สร้างโครงสร้างองค์กรให้ครบก่อน แล้วแก้ไฟล์ตามที่ระบบแจ้ง

**ถาม: หน้าเว็บไม่อัปเดตหลังปรับปรุงระบบ**
ตอบ: กด Ctrl พร้อม Shift พร้อม R หนึ่งครั้งเพื่อโหลดหน้าใหม่ให้สด

## 14. ปัญหาที่อาจเจอ และวิธีแก้

**อาการ: เปิด/ปิด Claude แล้วขึ้นว่ารหัสผิด**
- สาเหตุ: กรอกรหัส Admin (Master) ไม่ถูก
- วิธีแก้: กรอกรหัส Master Admin ปัจจุบันให้ถูกต้อง ถ้าจำไม่ได้ให้เปลี่ยนรหัสที่การ์ด "รหัส Master Admin" ก่อน

**อาการ: กด "สำรองตอนนี้" แล้วขึ้นว่าสำรองไม่สำเร็จ**
- สาเหตุ: อาจมีงานสำรองเดิมกำลังทำอยู่ หรือพื้นที่ดิสก์บนเซิร์ฟเวอร์เต็ม
- วิธีแก้: รอสักครู่แล้วลองใหม่ ถ้ายังไม่ได้ให้ลบไฟล์สำรองเก่าที่ไม่ต้องการออกก่อน หรือแจ้งผู้ดูแลเซิร์ฟเวอร์ให้ตรวจพื้นที่ดิสก์

**อาการ: เผลอกดลบข้อมูลในโซนอันตราย**
- สาเหตุ: กดปุ่มในโซนอันตรายและพิมพ์ DELETE ยืนยันไปแล้ว
- วิธีแก้: ข้อมูลที่ลบกู้เองไม่ได้ ต้องกู้จากไฟล์สำรอง — หากมีไฟล์สำรองล่าสุด ให้แจ้งผู้ดูแลเซิร์ฟเวอร์กู้คืนให้ นี่คือเหตุผลที่ต้องสำรองก่อนลบทุกครั้ง
