# คู่มือผู้ดูแลระดับสูง (Super Admin) — ระบบ HR-Interview

สำหรับ: ผู้ดูแลระบบระดับสูง / ผู้ดูแลเซิร์ฟเวอร์

คู่มือเล่มนี้ครอบคลุมงานของผู้ดูแลระดับสูง คือการสร้างและจัดการบริษัท (tenant) และการสำรองข้อมูลทั้งระบบ รวมถึงวิธีกู้คืนข้อมูลบนเซิร์ฟเวอร์ — Super Admin ดูแลภาพรวมระดับเซิร์ฟเวอร์ ไม่เข้าไปยุ่งกับข้อมูลภายในของแต่ละบริษัท (นั่นเป็นหน้าที่ของ Admin แต่ละบริษัท)

---

## 1. เริ่มต้น — เข้าและออกจากระบบ

### 1.1 เข้าสู่ระบบในฐานะผู้ดูแลระดับสูง

1. เปิดเบราว์เซอร์ (Chrome, Edge, Safari หรือ Firefox)
2. พิมพ์ที่อยู่เว็บของระบบตามด้วย `/super/login` เช่น `https://ชื่อเว็บ/super/login` แล้วกด Enter
3. กรอกรหัส Super Admin
4. กดปุ่มเข้าสู่ระบบ

> ควรเปลี่ยนรหัส Super Admin เริ่มต้นทันทีหลังติดตั้งระบบ (ดูหัวข้อ 5)

### 1.2 ออกจากระบบ

กดปุ่ม "ออกจากระบบ" ที่มุมขวาบนทุกครั้งเมื่อใช้งานเสร็จ

### 1.3 เมนูหลักของ Super Admin

- จัดการบริษัท — สร้าง/ดู/แก้ไข/ลบบริษัท
- สำรองข้อมูล — สำรองทั้งระบบและตั้งเวลาสำรองอัตโนมัติ

---

## 2. สร้างบริษัทใหม่ (Tenant)

แต่ละบริษัทมีฐานข้อมูลแยกกันสมบูรณ์ เมื่อสร้างบริษัทใหม่จะได้ที่อยู่เว็บเฉพาะของบริษัทนั้น (`/t/รหัสบริษัท`) เพื่อส่งให้ Admin ของบริษัทนั้นเข้าใช้งาน

### ถ้าอยากสร้างบริษัทใหม่

1. ที่หน้า "จัดการบริษัท" ไปที่การ์ด "สร้างบริษัทใหม่"
2. กรอก **Tenant ID** (รหัสบริษัทที่ใช้ในลิงก์ ใช้ได้เฉพาะตัวอักษร a-z ตัวเลข 0-9 และขีดกลาง เช่น `companyA` หรือ `siam-snacks`)
3. กรอก **ชื่อบริษัท** (ภาษาไทยหรืออังกฤษ เช่น "บริษัทขนมสยาม จำกัด")
4. กรอก **รหัส admin เริ่มต้น** ของบริษัทนั้น (ถ้าเว้นว่าง ระบบจะใช้รหัสเริ่มต้นมาตรฐานให้)
5. กดปุ่ม "สร้าง"
6. ระบบจะแสดงลิงก์เข้าระบบของบริษัทนั้น

### หลังสร้างเสร็จ ให้ส่งข้อมูลให้ Admin ของบริษัท

ส่ง 2 อย่างนี้ให้ผู้ดูแลระบบของบริษัทนั้น:

1. **ลิงก์เข้าระบบ** ของบริษัท (คัดลอกได้จากปุ่ม copy ในรายการบริษัท) ซึ่งลงท้ายด้วย `/t/รหัสบริษัท`
2. **รหัส admin เริ่มต้น** ที่ตั้งไว้ (ผู้ดูแลบริษัทจะเข้าด้วยชื่อผู้ใช้ `admin` และรหัสนี้ แล้วควรเปลี่ยนรหัสเองทันที)

**ตัวอย่าง:** ลูกค้าใหม่ชื่อ "บริษัทขนมสยาม" ให้คุณกรอก Tenant ID เป็น `siam-snacks` ชื่อบริษัท "บริษัทขนมสยาม จำกัด" ตั้งรหัส admin เริ่มต้น กด "สร้าง" แล้วคัดลอกลิงก์ `https://ชื่อเว็บ/t/siam-snacks` ส่งให้ผู้ดูแลของบริษัทพร้อมรหัส admin

### จัดการบริษัทที่มีอยู่

ในรายการบริษัทแต่ละแถวมีปุ่ม:

- "เปิด" — เปิดหน้าเข้าระบบของบริษัทนั้น
- "เปลี่ยนชื่อ" — เปลี่ยนชื่อบริษัท
- "เปลี่ยน URL ID" — เปลี่ยนรหัสบริษัทในลิงก์ (ผู้ที่กำลังใช้งานอยู่จะต้องเข้าระบบใหม่)
- "reset admin pw" — ตั้งรหัส admin ของบริษัทนั้นใหม่ (ใช้เมื่อ Admin ของบริษัทลืมรหัส)
- "ลบ" — ลบบริษัทและข้อมูลทั้งหมด (ต้องพิมพ์ `DELETE` ยืนยัน ลบแล้วกู้ไม่ได้)

## 3. สำรองข้อมูลทั้งระบบ

หน้า "สำรองข้อมูล" (`/super/backup`) ใช้สำรองข้อมูล **ทุกบริษัทและการตั้งค่าระบบทั้งหมด** เป็นไฟล์บีบอัดไฟล์เดียว ที่ใช้กู้คืนทั้งเซิร์ฟเวอร์ได้

เข้าหน้านี้ได้จากเมนู "สำรองข้อมูล" ด้านบน หรือกดการ์ด "สำรองข้อมูลทั้งระบบ" ในหน้าจัดการบริษัท

### ถ้าอยากสำรองข้อมูลตอนนี้

1. ที่หน้าสำรองข้อมูล ไปที่การ์ด "สำรองตอนนี้"
2. กดปุ่ม "สำรองตอนนี้"
3. รอสักครู่ จะขึ้นข้อความว่าสำรองสำเร็จพร้อมชื่อไฟล์และขนาด
4. ไฟล์ใหม่จะปรากฏในรายการ "ไฟล์สำรองที่มีอยู่" ด้านล่าง

### ถ้าอยากดาวน์โหลดหรือลบไฟล์สำรอง

- กดปุ่ม "ดาวน์โหลด" หลังไฟล์ที่ต้องการ เพื่อบันทึกลงเครื่องคุณ
- กดปุ่ม "ลบ" เพื่อลบไฟล์สำรองที่ไม่ต้องการ (ระบบจะถามยืนยันก่อน ลบแล้วกู้ไฟล์นั้นไม่ได้)

> สำคัญมาก: ควร **ดาวน์โหลดไฟล์สำรองไปเก็บนอกเซิร์ฟเวอร์** (เช่น เครื่องของคุณ หรือ cloud) อย่างสม่ำเสมอ เพราะถ้าเซิร์ฟเวอร์เสียหาย ไฟล์ที่อยู่บนเซิร์ฟเวอร์อย่างเดียวก็หายไปด้วย

### ถ้าอยากตั้งค่าสำรองอัตโนมัติ

ค่าเริ่มต้นคือ **ปิดไว้** เปิดได้ที่การ์ด "สำรองอัตโนมัติ"

1. กดสวิตช์ที่การ์ด "สำรองอัตโนมัติ" ให้เปิด
2. ตั้ง **เวลาที่สำรอง (ทุกวัน)** เช่น 02:00 (เวลาไทย) — ควรตั้งช่วงกลางดึกที่คนใช้งานน้อย
3. ตั้ง **เก็บย้อนหลัง (จำนวนชุด)** เช่น 14 คือเก็บไฟล์สำรองล่าสุด 14 ชุด เมื่อครบระบบจะลบชุดเก่าสุดให้อัตโนมัติ
4. กดปุ่ม "บันทึกการตั้งค่า"

การ์ดจะแสดงเวลาที่สำรองอัตโนมัติล่าสุดให้เห็นด้วย

> การสำรองอัตโนมัติทำเฉพาะ "ทั้งระบบ" เท่านั้น · แม้เปิดสำรองอัตโนมัติแล้ว ก็ยังควรดาวน์โหลดไฟล์ไปเก็บนอกเซิร์ฟเวอร์เป็นระยะ

## 4. กู้คืนข้อมูล (Restore) บนเซิร์ฟเวอร์

การกู้คืนต้องทำบนเซิร์ฟเวอร์ (ไม่มีปุ่มกู้คืนในหน้าเว็บ เพื่อความปลอดภัย) — อ้างอิงเอกสาร Deploy (`docs/DIGITALOCEAN-DEPLOY.md` ขั้นที่ 10)

ขั้นตอนคร่าว ๆ บนเซิร์ฟเวอร์:

1. หยุดแอปก่อน: `pm2 stop hr-interview`
2. แตกไฟล์สำรองทับข้อมูลเดิม (แทน `<ไฟล์>` ด้วยชื่อไฟล์สำรองที่ต้องการกู้):
   `tar -xzf backups/system/<ไฟล์>.tar.gz -C /opt/hr-interview`
3. เริ่มแอปใหม่: `pm2 start hr-interview`

> สำหรับไฟล์สำรองรายบริษัท (ที่ Admin สร้าง) ไฟล์จะอยู่ใต้ `backups/tenants/<รหัสบริษัท>/` กู้คืนด้วยวิธีเดียวกัน · หากไม่คุ้นเคยกับคำสั่งบนเซิร์ฟเวอร์ ให้ประสานงานกับผู้ดูแลเซิร์ฟเวอร์ และควรทำในช่วงที่มีคนใช้งานน้อย

---

## 5. เปลี่ยนรหัส Super Admin

1. ที่หน้าจัดการบริษัท กดเมนู "เปลี่ยนรหัส Super-admin" ด้านบน
2. พิมพ์รหัสใหม่ (อย่างน้อย 6 ตัวอักษร)
3. กดตกลง — ครั้งหน้าให้ใช้รหัสใหม่นี้เข้าระบบ

## 6. คำถามที่พบบ่อย (FAQ)

**ถาม: Super Admin แก้ผู้ใช้หรือดูข้อมูลภายในบริษัทได้ไหม**
ตอบ: ไม่ได้ (และไม่ควร) Super Admin ดูแลเฉพาะการสร้าง/ลบบริษัทและการสำรองข้อมูลทั้งระบบ การจัดการผู้ใช้ โครงสร้าง และการสัมภาษณ์ เป็นหน้าที่ของ Admin แต่ละบริษัท

**ถาม: Admin ของบริษัทลืมรหัสผ่าน ทำยังไง**
ตอบ: ที่รายการบริษัท กดปุ่ม "reset admin pw" ของบริษัทนั้น ตั้งรหัสใหม่ แล้วแจ้งรหัสใหม่ให้ Admin ของบริษัท

**ถาม: ต่างกันอย่างไรระหว่างสำรอง "ทั้งระบบ" กับสำรอง "รายบริษัท"**
ตอบ: สำรองทั้งระบบ (Super Admin) เก็บทุกบริษัทและการตั้งค่าระบบในไฟล์เดียว ใช้กู้คืนทั้งเซิร์ฟเวอร์ · สำรองรายบริษัท (Admin แต่ละบริษัททำเอง) เก็บเฉพาะข้อมูลบริษัทนั้น การสำรองอัตโนมัติทำเฉพาะแบบทั้งระบบเท่านั้น

**ถาม: ตั้งสำรองอัตโนมัติแล้ว ยังต้องดาวน์โหลดเองอีกไหม**
ตอบ: ควรดาวน์โหลด เพราะไฟล์อัตโนมัติยังเก็บอยู่บนเซิร์ฟเวอร์เดียวกัน ถ้าเซิร์ฟเวอร์เสียก็หายไปด้วย การดาวน์โหลดไปเก็บที่อื่นคือหลักประกันชั้นสุดท้าย

## 7. ปัญหาที่อาจเจอ และวิธีแก้

**อาการ: สร้างบริษัทไม่สำเร็จ ขึ้นว่ารหัสบริษัทซ้ำ หรือรูปแบบไม่ถูก**
- สาเหตุ: Tenant ID ซ้ำกับที่มีอยู่ หรือใช้อักขระที่ไม่อนุญาต
- วิธีแก้: ใช้ Tenant ID ที่ไม่ซ้ำ และใช้เฉพาะ a-z, 0-9, ขีดกลาง (ห้ามเว้นวรรคหรืออักขระพิเศษ)

**อาการ: กด "สำรองตอนนี้" แล้วขึ้นว่าสำรองไม่สำเร็จ**
- สาเหตุ: อาจมีงานสำรองเดิมกำลังทำอยู่ (ระบบล็อกไม่ให้สำรองซ้อนกัน) หรือพื้นที่ดิสก์เต็ม
- วิธีแก้: รอให้งานเดิมเสร็จแล้วลองใหม่ หรือลบไฟล์สำรองเก่าที่ไม่ต้องการออก ถ้ายังไม่ได้ให้ตรวจพื้นที่ดิสก์บนเซิร์ฟเวอร์ (`df -h`)

**อาการ: หลังกู้คืนแล้ว เข้าระบบไม่ได้ หรือข้อมูลไม่ครบ**
- สาเหตุ: อาจแตกไฟล์ผิดตำแหน่ง หรือใช้ไฟล์สำรองผิดชุด
- วิธีแก้: ตรวจว่าแตกไฟล์ทับที่ `/opt/hr-interview` ถูกต้อง และใช้ไฟล์สำรองชุดที่ต้องการ จากนั้นสั่ง `pm2 restart hr-interview` แล้วดู log ด้วย `pm2 logs hr-interview`

**อาการ: ลืมรหัส Super Admin**
- สาเหตุ: จำรหัสไม่ได้
- วิธีแก้: ต้องแก้ไฟล์ข้อมูลบนเซิร์ฟเวอร์โดยตรง ให้ผู้ดูแลเซิร์ฟเวอร์ดำเนินการ (จึงควรเปลี่ยนและเก็บรหัสไว้ในที่ปลอดภัยตั้งแต่แรก)
